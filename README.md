School Management Application - සුරැකි
In Sri Lankan school system doesn't have strong parent-school connection, therefore parents and school missed monitor student performance effectively and easily. So, We built full stack web application called "Sureki"  for Sri Lankan schools, to manage students records, daily attendance, teacher management, track student progress, alert poor performance school wide notifications and increase parent awareness to improve child safety. 

I involved as the backend developer for this project. We use monolithic architecture and our core technology stack was HTML,CSS and JS, Node.JS(Express framework) and PostgreSQL. Additionally we use Bcrypt, Axios, NodeMailer, Postman and JWT. We use SMS as primary communication method due to SMS is an easy accessible method.

The application is deployed on Render platform.
